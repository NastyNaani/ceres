# CERES — Brand Kit

Food clarity at the shelf. Dark-luxury visual language: void black + brushed
platinum silver. Clear verdicts with dry wit.

---

## 1. Brand essence

| | |
|---|---|
| **Name** | Ceres (Roman goddess of agriculture / grain) |
| **Tagline** | Know what you buy |
| **Personality** | Precise, quiet, premium. Clear verdicts — sharp, never cartoonish. |
| **Visual metaphors** | Viewfinder, barcode beam, brushed metal grade marks |
| **Aesthetic** | Void black + brushed silver |

## 2. Typography

- Display: Orbitron
- Body: Manrope

## 3. Color

| Token | Hex | Use |
|---|---|---|
| `void` | `#040405` | App background |
| `silver` | `#D6D9DF` | Brand metal |
| `success` | `#7BD4A8` | Good / Excellent |
| `caution` | `#D6B474` | Okay |
| `danger` | `#E08A92` | Poor |
